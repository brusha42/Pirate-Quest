# Pirate Quest

2D-платформер на Unity 6: пират поднимается по башне, улучшает протезы и доставляет послание королю.

Играть: [https://brysha42.itch.io/pirate-quest](https://brysha42.itch.io/pirate-quest)

## Открыть исходники

Проект Unity лежит в папке `Pirate Quest/`.

1. Поставьте **Unity 6000.3.21f1** через Unity Hub.
2. Hub → **Open** → выберите папку `Pirate Quest`.
3. Стартовая сцена: `Assets/Scenes/Campaign/Dock.unity`.

## Управление

- A/D — ходьба, Space — прыжок, Shift — рывок
- ЛКМ — сабля, ПКМ — крюк
- New expedition → seed `20260918` → Set sail
